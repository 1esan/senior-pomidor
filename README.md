# Сеньор Помидор

Личная сборка помощника для откликов hh.ru, отчётности и интервью с ГигаРекрутёром. Этот репозиторий фиксирует исходный код, интерфейс, тесты и изменённую встроенную библиотеку. Это снимок существующей сборки, а не готовый установщик для другого пользователя.

## Локальные данные

Профиль `giga_profile.json`, настройки личного подключения, `.state/`, `.browsers/`, журналы, статистика и персональные инструкции намеренно не хранятся в Git. Они остаются в рабочей папке и требуют отдельного резервного копирования. Репозиторий не содержит GPT-адаптер: подключение к нему настраивается локально.

Старый персональный README сохранён в `.state/git-migration-*/README.md`. Инструкция `Как_пользоваться.md` остаётся локальной. Не выполнять `git clean -fdx`: эта команда может удалить исключённые пользовательские данные.

## Разработка

См. [порядок работы с Git](GIT_WORKFLOW.md). Основная ветка — `main`; доработки — `codex/<название>`. Перед коммитом проверяется содержимое индекса, а не только рабочие файлы.

Зависимости зафиксированы в `requirements-lock.txt`. Встроенная библиотека устанавливается из `./vendor/hh-applicant-tool`; окружение и браузеры не коммитятся. На имеющемся Mac запуск и пути сохранены. Воспроизводимость установки на другой машине ещё требует отдельной проверки.

Сведения о встроенном проекте: [THIRD_PARTY.md](THIRD_PARTY.md).
