# Сеньор Помидор

Локальный помощник для поиска вакансий hh.ru, работы с откликами, статистикой и первичным интервью в Telegram. В репозитории находятся программа, интерфейс, тесты и изменённая встроенная библиотека; личные анкеты, переписки, история откликов и авторизация хранятся отдельно на компьютере владельца.

## Состояние сборки

Это исходный код и первичная настройка для macOS, а не готовый установщик. Переносимость на Windows и полноценная установка на чистом компьютере ещё не подтверждены. В комплект не входят подписка, ключи и отдельный GPT-адаптер: его доступность и порядок подключения зависят от отдельного проекта и аккаунта пользователя.

Начало работы: [первичная настройка](FIRST_RUN.md). Она создаёт пустой локальный профиль и открывает панель в режиме настройки, где сервер блокирует запуск операций и подключение аккаунтов. Подготовка не отправляет отклики. Не копируйте чужие настройки, сессии и профили между устройствами.

## Личные данные и Git

`giga_profile.json`, `personal_launcher.json`, `cover_letter_settings.json`, `test_sources.json`, `.state/`, `.browsers/`, `.venv/`, `logs/`, локальная статистика и отчёты не должны попадать в Git или передаваться вместе с приложением. Не выполняйте `git add -f` для них и не используйте `git clean -fdx` в рабочей папке: эта команда может удалить исключённые данные. Подробнее: [работа с Git](GIT_WORKFLOW.md).

Промпты используют данные владельца из локальной анкеты и резюме; другой пользователь должен заполнить и проверить собственные сведения. Удаление данных из текущих файлов не удаляет их из предыдущих коммитов: перед открытием репозитория или передачей его истории нужна отдельная проверка истории.

## Подключения и ограничения

Для полноценной работы потребуются собственные аккаунты hh.ru и, для интервью, Telegram. Секреты вводятся только в соответствующих официальных интерфейсах. Автоотклики и работа с тестами зависят от доступности площадки и условий её использования; перед использованием проверяйте актуальные правила hh.ru. Режим отправки включается отдельно и требует явного подтверждения.

Интервью и генерация писем зависят от внешнего локального ИИ-адаптера; без него панель может открыться, но функции генерации недоступны. Если совместимый адаптер уже установлен, его абсолютный путь и путь к Node.js задаются в локальном `personal_launcher.json`:

```json
{
  "adapter_dir": "/absolute/path/to/your/adapter",
  "node": "/absolute/path/to/node"
}
```

Ключ остаётся в локальной папке адаптера и не указывается в Git. Установка и авторизация самого адаптера в этот репозиторий не входят. Автоматический запуск интервью использует предусмотренный сборкой протокол Luna, совместимость с произвольными моделями и адаптерами не заявлена.

Встроенная библиотека изменена относительно стороннего проекта; её происхождение и ограничения распространения описаны в [THIRD_PARTY.md](THIRD_PARTY.md).
