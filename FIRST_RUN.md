# Первичная настройка

На macOS установи Python 3.11 или новее. Затем запусти `Первичная_настройка.command` или из папки проекта выполни:

```sh
python3 first_run.py
```

Скрипт создаст локальное `.venv`, установит закреплённые Python-зависимости, скопирует пустой `profile-template.example.json` в `giga_profile.json` с правами владельца и откроет панель настройки. При отсутствии локальных параметров сопроводительного письма создаст пустой `cover_letter_settings.json`. Уже существующие файлы останутся нетронутыми. На другой машине не копируй `.state`, браузерные профили, журналы или авторизационные файлы.

До сохранения профиля настрой список работодателей, с которыми нельзя связываться. Панель пока не редактирует этот список: открой локальный `giga_profile.json` в текстовом редакторе. Добавь каждую исключаемую компанию в `excluded_employers` как объект с названием, непустым списком `aliases` и списком строковых HH ID (он может быть пустым). Защита потребует подтвердить корректность структуры. Если исключений действительно нет, оставь `excluded_employers` пустым и вручную измени `employer_exclusions_confirmed` с `false` на `true`: это явное решение разрешить контакт с любым установленным работодателем. Без этого подтверждения контакты останутся заблокированы. Не меняй `employer_contact_policy.strict` на `false`.

Панель первичной настройки работает в режиме настройки: запросы на подключение аккаунтов, обновление отчётов и запуск операций блокируются сервером. Сначала заполни личные данные и резюме, сохрани профиль и подтверди его достоверность. Этот режим не отправляет отклики и не требует запуска GPT-адаптера.

Для проверки уже установленного окружения используй `python3 first_run.py --skip-install`. Добавь `--no-open`, если браузер не должен открываться автоматически.

Для последующего подключения hh.ru и Telegram Web нужен отдельный браузер Playwright; установка Python-зависимостей сама по себе его не скачивает. Устанавливай его после настройки окружения командой `PLAYWRIGHT_BROWSERS_PATH=.browsers .venv/bin/python -m playwright install chromium` из папки проекта. Полная проверка авторизации и переноса сессий на чистой машине ещё не проведена.

После сохранения профиля закрой панель настройки и используй `Открыть_панель.command` для обычной панели. Если порт уже занят, первичная настройка остановится и не будет перезапускать существующее приложение. Для генерации потребуется отдельно установленный и настроенный ИИ-адаптер; инструкции о его локальном пути приведены в README.
