# Встроенный код

`vendor/hh-applicant-tool` основан на [s3rgeym/hh-applicant-tool](https://github.com/s3rgeym/hh-applicant-tool), метаданные локальной базы указывают 2.1.0. В библиотеку внесены локальные изменения, поэтому код включён как обычные файлы, не submodule. Точный исходный commit архивной поставки неизвестен. Обновление vendor требует просмотра разницы и проверок, а не установки поверх.

Исходные авторские сведения и README сохранены внутри vendor. На момент проверки GitHub не сообщает лицензию upstream; отдельный LICENSE в локальной поставке не обнаружен. Новая лицензия исходному проекту не присваивается. Репозиторий создан приватным.
